# Atanga Joseph — Portfolio

A modern, high-performance personal portfolio website built with Next.js, React, TypeScript, and Tailwind CSS. Showcasing web development projects including e-commerce platforms, SaaS dashboards, corporate websites, and full-stack applications.

## Features

- **Next.js 16** — App Router with server components and API routes
- **React 19** — Latest React with concurrent features
- **TypeScript** — Type-safe development throughout
- **Tailwind CSS 4** — Utility-first responsive styling with glassmorphism design
- **Responsive Design** — Mobile-first, fully responsive layouts
- **Smooth Animations** — CSS animations and transitions for polished UX
- **SEO Optimized** — Metadata and Open Graph tags on every page

## Pages

- **Home** — Hero section, featured projects, services overview, testimonials, and newsletter signup
- **Portfolio** — Full project grid with live demo links
- **Services** — Detailed service offerings with benefits and process overview
- **About** — Bio, stats, skills, and experience
- **Blog** — Articles on web development, technology, and business
- **Blog Post** — Individual blog posts with full content
- **Contact** — Contact form with project inquiry, location, and social links
- **Privacy Policy** — Data privacy information
- **Terms of Service** — Website usage terms

## Getting Started

First, install dependencies:

```bash
npm install
```

Then run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build

```bash
npm run build
```

## Deploy

Easiest deployment via [Vercel](https://vercel.com/new).
